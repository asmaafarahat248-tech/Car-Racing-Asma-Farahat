CAR RACING MULTIPLAYER — النشر من أي شبكة إنترنت
==================================================

هذه نفس نسخة اللعبة النهائية بالشهادات والعد التنازلي والأصوات، وكل الملفات جاهزة للنشر.

1. فكّي ضغط الملف ZIP. أنشئي مستودع GitHub من نوع PRIVATE، وارفعي محتويات المجلد كلها إلى الصفحة الرئيسية للمستودع (مهم أن يكون server.js وpackage.json وrender.yaml في جذر المستودع، مش داخل فولدر ثانٍ).
2. افتحي https://dashboard.render.com ثم New → Web Service → Connect GitHub Repository واختاري المستودع.
3. تأكدي أن Runtime: Node، والخطة Free، وBuild Command: npm install --omit=dev، وStart Command: npm start، وHealth Check Path: /health.
4. اضغطي Create/Deploy وتابعي حالة Live. الخدمة تمنحك رابط https://...onrender.com عندما ينجح النشر.
5. افتحي الرابط من جهازك واختاري TEACHER · HOST؛ شاركي QR/كود الغرفة مع الطلاب، ثم ابدئي سباقكم. كل جهاز ممكن يبقى على شبكة مختلفة، لكن لازم يكون فيه إنترنت.

اختبار النشر: افتحي https://عنوان-لعبتك/health وتأكدي من ظهور {"ok":true,...} قبل بدء الحصة.

ملاحظات مهمة:
* لسه ما تمش النشر على حسابك: مفيش رابط نهائي حتى تتم خطوة ربط Render وGitHub.
* Render Free يمكن إيقاف السيرفر مؤقتًا بعد 15 دقيقة من عدم الاستخدام، والغرف الحالية بتضيع عند إعادة تشغيله. افتحي اللعبة قبل الحصة وشغّلي الغرفة من جديد.
* احفظي بيانات الطلاب بأسماء أولى أو ألقاب من غير معلومات خاصة.
* الملفات في Repo خاص حماية أفضل لمجهودك.
* الخاصية Multiplayer تتطلب السيرفر؛ فتح index.html لوحده يشغّل Single Player فقط.
* لم يُختبر ضغط عشرات الأجهزة الحقيقية في الفصل بعد؛ جربيها بـ 3 إلى 5 أجهزة أولًا.
